# Personal Tracker — Official Website

Official website for the **Personal Tracker** mobile application.

The website is designed to provide users with a clear and trustworthy overview of the app, its existing features, screenshots, frequently asked questions, privacy information, and the official Google Play download link.

The website is **not a web version of the Personal Tracker app**. It is a simple informational and marketing website for the mobile application.

---

## 1. Website Purpose

The primary purpose of this website is to answer:

> **What is Personal Tracker, what can it do, and where can I get it?**

The website should allow a visitor to:

* Understand what Personal Tracker is.
* Learn about its existing features.
* See real screenshots from the mobile app.
* Understand how Health Connect is used.
* Find answers to common questions.
* Read the Privacy Policy.
* Access Terms if applicable.
* Contact support if a valid support contact is available.
* Download the application from Google Play.

---
